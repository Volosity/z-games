# games/

Story files the shell can play live here. The shell plays them
**untouched** — it never modifies a story file.

- `figaro/` — the bundled starter game: **Figaro** by Victor Gijsbers,
  GPL v3, a licensed component included unmodified with its source.
  See `figaro/NOTICE.md` and the root `CREDITS.md`. It is not the
  entrant's work.

Players can also open their own `.z3` / `.z5` / `.z8` / `.zblorb`
files from the shell's "Open a game file" button — nothing needs to
live in this folder for bring-your-own play to work.
